AI security ↗

AgentRed

A security evaluation framework for AI agents. It runs adversarial scenarios, records every tool call at the MCP trust boundary, and checks whether security invariants hold. It judges the agent's actual behavior, not just what the model says.

  • Deterministic checks for secret exfiltration, tenant isolation, approval gates, and untrusted-content influence
  • Grounded in IAM principles: least privilege and authorization scope
  • Python
  • MCP
  • LangGraph
  • LLM Evaluation

Turns any photo into a printable connect-the-dots puzzle. It extracts an outline, places dots based on curvature, numbers the sequence, and exports a PDF with an answer key. Optional AI judges tune the difficulty.
